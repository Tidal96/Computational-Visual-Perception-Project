## Processing and credits

Originals: aligned FFHQ exports from a pinned mirror revision, unmodified by this project. Mooney processing: grayscale, Gaussian blur (sigma 8 px; kernel 49), global threshold targeting 22% or 28% white pixels. Per-image settings and all individual photo credits are in the analysis files. No model results were used to screen the images.
